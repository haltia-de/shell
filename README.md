# b8k-shell

Оболочка планшета без рабочего стола — для Lenovo YOGA Tablet 10 (B8000-H)
с [lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux), но
не привязанная к нему: она запускает программы и показывает их крупно для
пожилого человека.

- **Панель** слева (waybar) с кнопкой «Домой», закреплёнными и открытыми
  программами, ящиком (громкость, яркость, Wi-Fi), батареей и часами.
- **Домашний экран** (`b8k-home`): все программы плитками, время, дата,
  погода; долгое нажатие закрепляет программу на панели.
- **«✕» в правом верхнем углу** (`b8k-close`) закрывает любую программу,
  с вопросом; **заставка** (`b8k-splash`) пока программа запускается.
- **Вопросы оболочки** на fuzzel (`b8k-ask`), меню выключения.
- **Защита от случайных касаний** (`b8k-touchguard`) и вибрация на
  касание; **кнопка питания** (`b8k-sleep.py`): экран, меню, сон.
- **Экранная клавиатура** (wvkbd с раскладками b8k), **уведомления** (mako),
  **тема GTK** `b8k`: высокая шапка с местом под «✕», крупные вопросы.

Программы оболочка знает только по стандартам freedesktop: `.desktop`-файлы
(`X-B8K-Home`, `X-B8K-Replaces`, `X-B8K-Windows`), счётчики Unity
LauncherEntry, запреты сна logind, XDG autostart. Решение и словарь — в
репозитории устройства: `docs/adr/0001-three-layers.md`, `CONTEXT.md`.

Установка: пакет Alpine `b8k-shell` (armv7) из выпусков GitHub, подписан
ключом проекта ([b8k-ci](https://github.com/trudenboy/b8k-ci)); его собирает
CI по тегу `vX.Y.Z` родным компилятором в Alpine armv7
(`tools/native-build.sh`). Вручную: `sh build.sh` (кросс-сборка в контейнере
`b8000h-build:3.24`, результат в `/opt/b8000h/tools` и `/opt/b8000h/out`) и
`sh install.sh [ROOT]`; пути — `/usr/local/{bin,sbin,share/b8k}`. Как
запускается сеанс и какой композитор — дело устройства (`phoc -C
/usr/local/share/b8k/phoc.ini -E b8k-launcher`).
